# Doodle - A Sophisticated Chat Experience ✨📱💬

Doodle is a cutting-edge, secure chat application built with Flutter and Firebase. It delivers seamless real-time messaging, intelligent authentication, and immersive cloud notifications—all wrapped in a sleek and aesthetically refined UI.

## 🚀 Features

### 🔐 Authentication
- Effortless Login with Email & Password
- Seamless Sign in with Google
- Instant Anonymous Access
- Smooth User Registration
- Secure Logout Mechanism

### 💬 Messaging
- Fluid real-time chat interactions
- Edit and refine sent messages
- Elegant seen/unseen message indicators
- Snippet previews in the chat list
- Time-stamped last messages
- Comprehensive date & time message tracking

### 🔔 Notifications
- Instant cloud notifications for new messages
- Personalized local notifications

### 🔥 Firebase Integration
- Scalable Cloud Firestore for data handling
- Robust Firebase Authentication
- Dynamic Firebase Messaging for real-time updates

### 🎨 Aesthetic & Intuitive UI
- Engaging and polished user interface
- Interactive profile picture previews
- Custom emoji picker for expressive conversations

## 📦 Installation & Setup

### 1️⃣ Clone the Repository
```sh
git clone https://github.com/your-username/doodle.git
cd doodle
```

### 2️⃣ Install Dependencies
```sh
flutter pub get
```

### 3️⃣ Setup Firebase
- Create a Firebase project on [Firebase Console](https://console.firebase.google.com/)
- Download `google-services.json` (for Android) and `GoogleService-Info.plist` (for iOS)
- Place them in the respective `android/app/` and `ios/Runner/` directories

### 4️⃣ Run the App
```sh
flutter run
```
